# 首版验证记录

验证对象：Godot 4.5.1、Windows、OpenGL Compatibility、RTX 3070。本记录只评价当前可玩原型，不代表成品美术、人工手感或全部硬件通过验收。

## 规则与存档

`project/reports/tests.json` 记录三个原生测试组：

- `test_rules.gd`：6 人比赛、倒计时拒绝驾驶动作命令、氮气消耗与重复使用限制、R 保持进度/清除运动/冷却、暂停冻结、逆行和跳检查点被拒绝、36 个顺序检查点结算、冲线车退出碰撞、预览与装备分离、装备进入比赛、道具箱冷却、护盾挡一次命中、无保护时导弹减速、重赛清理状态。
- `test_profile.gd`：车辆/时装/最佳成绩/设置落盘再读取；损坏文件回退默认值；使用独立临时存档，不覆盖玩家数据。
- `test_sources.gd`：主场景依赖脚本可编译实例化。

## 运行与输入

`evidence/qa/report.json` 与 `events.jsonl` 是完整两局运行的结果。驾驶先使用油门、转向和漂移输入，再切换到调用同一车辆规则的 AI 控制。Space、E、R、Esc 以原生按键事件送入游戏；车库选车、换装、装备、模式选择和返回车库以原生视口鼠标事件操作。

检查点、氮气、道具拾取/使用、命中、暂停、复位与完赛都有事件记录。护盾挡击中另有规则测试和 `qa_attempt2` 的运行证据。两局三圈均完赛后退出。自动驾驶不能替代人工对漂移难度、竞速乐趣及平衡性的判断。

## 从录像发现并修复

| 症状 | 所属模块 | 修复 | 复查 |
|---|---|---|---|
| 场景顶面过曝，草地与路面发白 | 世界光照 | 降低日光与环境光，改用线性映射 | 新录像能够分辨路面、草地与车辆 |
| 轮胎陷入地面 | 碰撞与视觉对齐 | 统一车身碰撞底部、路面与地面高度 | 全圈车辆贴地，无持续下陷 |
| 先完赛的 AI 堵住终点 | 比赛规则 | 完赛车不再参与碰撞 | 两种模式均成功结算；新增回归断言 |
| 旋转路段之间露出草地楔形接缝 | 赛道几何 | 用连续三角形路面替换分段盒子 | 弯道与直线连续 |
| 转弯时追尾镜头滞后，近处对手遮住镜头 | 相机/呈现 | 更快的跟随阻尼、相机球体扫掠、隐藏极近对手模型 | 玩家和前路可见；紧邻赛车仍会短暂进入前景 |
| Space 可能被 HUD 暂停按钮焦点捕获 | UI 输入 | HUD 暂停按钮不接收键盘焦点，保留点击与 Esc | 原生 Space 输入进入氮气逻辑 |
| 起跑后镜头穿过门架横梁 | 场景 | 抬高横梁与标牌，使追尾相机可从下方经过 | 修复后起步及逐圈通过截图 |
| QA 鼠标合成事件使用错误坐标空间 | 验证脚本 | 使用原生 Viewport 本地坐标投递 | 真实按钮连接触发选车/装备/开始/返回 |

`qa_attempt1` 保存终点堵车失败，`qa_attempt2` 保存规则修复后的完整比赛，`qa_attempt3` 保存 QA 输入坐标失败，`qa_attempt4` 保存连续路面和输入验证，最终 `qa` 保存抬高门架后的版本。未把旧失败覆盖为成功。

录像来源是游戏进程内的实际视口帧，按连续序列编码为 `gameplay-review.mp4`。通过序列联系表审查全程，再放大关键帧检查车库、驾驶、漂移、氮气、道具、复位、暂停和结算；联系表不等于人工实时操作。录制约 4 fps，仅用于检查流程和视觉，不能据此宣称游戏渲染帧率。

## 工具能力缺口

实际调用公开 `GodotClient.playtest.record` 时，仓库当前实现报错：`AttributeError: 'GodotPlaytestClient' object has no attribute '_create_record_scene'`。未修改适配器。保留公开 `runtime.launch_game` 作为启动路径，用工程自带 QA 重放脚本在 Godot 进程中采集视口帧并离线编码。`run.py record` 因而等同于此 QA 录帧流程。

## 尚未验收

- 成品角色、赛车和场景美术：当前是低多边形占位模型，角色无骨骼动画，轮胎无独立转动动画。
- 音频：已接入合成提示音及随速度变调的临时引擎音；录像无音轨，未做听感、响度和混音验收。
- 尚无人工驾驶手感评测、30/120 Hz 专项对比、低配置机器或其他屏幕比例验证；设计目标不应被当成已测数据。
- 当前 UI 基于 1600×900 设计、1280×720 窗口运行，按 16:9 等比缩放。不同宽高比会留边。
- 未制作独立 Windows EXE、联机或商业级内容系统。

下一轮优先：人工驾驶反馈 → 漂移回正/小喷节奏调参 → 车手与赛车成品模型 → 更丰富的赛道和音效。
