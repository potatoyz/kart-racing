# 驾驶与连喷改版

用户要求：漂移松 Shift 后保留惯性，支持小喷、大喷、空中喷、落地喷、双喷及不同输入顺序。以下规则为本原型自己的可调版本，不宣称复刻 QQ 飞车的逐帧参数。

## 规则

- Shift + 方向起漂，持续按住可维持漂移。松 Shift 进入恢复抓地阶段，横向速度与转向角速度连续衰减；反打使车头回正并加快抓地恢复。漂移进入、持续、收尾分开处理，相机主要跟运动方向，不随车头瞬间甩动。
- 小喷：有效漂移收尾后 1.15 秒内点 J/W，一次性消耗资格；不再松 Shift 自动发喷。W 同时保留 WASD 的油门绑定，使用 WASD 时推荐 J；使用方向键时推荐 W。
- 大喷：Space/Ctrl 消耗一罐氮气，持续 2.1 秒。小喷与大喷不无限叠加速度；组合上限受车辆规则控制。
- 双喷：持续有效漂移至少 0.7 秒，累计侧滑角积分至少 0.16 rad·s，并反打至少 0.08 秒完成收尾；第一喷后 0.16–0.50 秒内再次点 J/W。第二喷不能靠按住或系统按键重复触发。
- 空中喷：真实离地至少 0.10 秒，且高度变化/离地速度满足起跳资格；当次飞行只能用一次。
- 落地喷：有效腾空至少 0.22 秒后着地，0.55 秒内点 J/W；只在落地事件授予，不因复位或静止接地授予。
- 输入容错：提前 0.12 秒点喷可缓存到有效窗口，不能长期预存或空按刷资格。
- 连招识别：C=大喷、W=小喷，支持 CW、WCW、CWW，以及空中喷接落地喷。HUD 显示窗口、第二喷节奏、当前漂移阶段及确认后的连招，不用按键意图冒充成功结果。
- 赛道加入两座真实碰撞跳台，所有赛车同样受重力与坡面影响。重置/受击/重赛清除未完成连招与临时喷气；暂停冻结窗口。
