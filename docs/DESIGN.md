## 玩家流程

不强加剧情。玩家参加晴空海岸的业余赛车节，目标是选择车辆与装束，完成比赛并刷新个人成绩。以下设定为设计提案。

| 阶段 | 预计游玩时间 | 世界时间 | 目标与顺序 | 入口 / 出口与分支 | 保留状态 |
|---|---|---|---|---|---|
| C1 车库 | 0–1 分钟 | 晴朗下午 | 选车、预览属性、换装、选模式 | 启动进入；开始比赛进入 C2 | 已装备车辆、时装、最佳成绩保存到本机 |
| C2 比赛 | 1–5 分钟 | 同一下午 | 倒计时、起步、漂移集气、超车、完成三圈 | 竞速/道具分支共用赛道；冲线进入 C3；暂停可回 C1 或重赛 | 本局进度仅在本局保留；R 只恢复位置 |
| C3 结算 | 5–6 分钟 | 同一下午 | 查看名次、时间、个人纪录 | 重赛回 C2；返回车库回 C1 | 最佳成绩按模式保存，重试不重复奖励 |

## 需求与验收

| ID | 阶段 | 行为与反馈 | 验收标准 |
|---|---|---|---|
| R1 驾驶 | C2 | W/S 或上下加减速、A/D 或左右转向，追尾相机和速度表 | 有惯性、草地减速、边界碰撞；30/60 Hz 行为稳定 |
| R2 漂移 | C2 | 转向 + Shift；车头与运动方向分离，轮迹与集气反馈；松 Shift 后惯性侧滑，反打回正 | 低速/直行不刷气；抓地连续恢复；有效漂移授予主动小喷/双喷窗口，详见驾驶 V2 |
| R3 氮气 | C2 | 漂移积累 100 气获得一罐，最多两罐；Space 消耗一罐 | 加速持续约 2 秒；无库存不触发；重置清除加速但不赠送资源 |
| R4 角色时装 | C1/C2 | 三套完整装束，车库预览、显式装备、比赛中可见 | 仅外观差异；重启后保持；预览不会自动装备 |
| R5 赛车 | C1/C2 | 平衡、极速、操控三种属性，模型轮廓不同 | 属性改变真实驾驶参数；重启保持选择 |
| R6 竞速赛 | C2/C3 | 三圈、5 名 AI、名次、计时、结算 | 必须按顺序通过检查点，逆行与 R 不增加圈数；AI 同样受赛道与道具影响 |
| R7 道具赛 | C2 | 拾取箱子得到导弹/护盾/加速，E 使用 | 同时持有一件；护盾挡一次命中；导弹针对前方范围内对手；竞速赛无道具 |
| R8 重置 | C2 | R 恢复最后安全检查点，短暂保护与提示 | 清零速度与漂移，不前进圈数；冷却防连按；离场自动复位 |
| R9 完整流程 | C1–C3 | 中文菜单、倒计时、暂停、结算与重赛 | 鼠标/键盘可操作菜单；暂停冻结比赛；重赛清除临时状态；存档损坏可恢复默认 |

## 参数与实现边界

Godot 4.5.1，GDScript；街机动力学使用 CharacterBody3D，控制速度方向与抓地插值，而非依赖拟真轮胎模拟。静态赛道碰撞体；检查点按顺序与行进方向验证；名次依据已通过检查点和当前段进度，冲线顺序固定。AI 根据前方路径曲率调速并转向，使用同样车辆更新及道具规则，不瞬移追赶玩家。

Mechanic 发布 snapshot / command / event 接口，负责比赛、车辆状态、碰撞、检查点、AI、道具与本地存档。Presentation 负责模型、相机、HUD、音效与事件反馈，通过公开接口读取。主场景只组装依赖。UI 布局借鉴 action_rpg 的无遮挡第三人称世界视图，按赛车活动改成 racing 布局。

拟定输入：WASD/方向键驾驶，Shift 漂移，Space 氮气，E 道具，R 复位，Esc 暂停。窗口失焦自动暂停。相机只有一个写入者，默认不晃动；常规 FOV 65°，加速最多 73°，低动态选项关闭 FOV 变化。复位直接切镜防穿场；开放赛道相机仍需碰撞查询。所有数值在实测后调整。
