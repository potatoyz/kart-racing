# 漂移接小喷镜头闪动修复

用户反馈：漂移后接小喷时镜头闪烁。优先逐帧检查漂移/抓地切换、相机追踪及碰撞避让。保持驾驶 V4 的输入响应，不通过加重普通转向来掩盖镜头问题。

已发现的代码风险：普通驾驶每帧直接设置相机朝向，漂移则平滑跟随运动方向。漂移收尾进入普通驾驶时，这两个分支可能把残留的镜头角度差瞬间清掉。同时，相机在渲染帧读取未插值的物理位置，喷气加速可能放大物理步进的可见跳动。

验收：先记录旧版原生逐帧镜头数据，再修复；覆盖小喷、双喷、CWW/WCW、空喷/落地喷，检查转角、相机相对车辆的位置与 FOV。普通转向的物理响应测试保持原门槛。出生/复位允许切镜，正常驾驶状态过渡必须连续。保存实际视口视频与原始帧；低帧率旧录像不作为此次闪烁的充分证据。
