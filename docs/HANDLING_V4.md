# 普通驾驶响应 V4

用户反馈：转向沉重、拖沓，不能指哪打哪。目标为街机式直接操控，并保留之前要求的漂移惯性与喷气技巧。

已验证的根因：普通驾驶也依次平滑方向输入、车头角速度、速度方向；普通满舵存在持续侧滑，松方向后角速度还在衰减。追尾相机再叠加方向和位置延迟。这是运动学控制器的响应链，不是车辆质量参数。

方案：普通抓地驾驶直接接受方向输入及目标转向角速度，速度方向快速贴合车头；漂移/腾空继续独立处理侧滑，防止把普通驾驶和漂移一起调成打滑。普通镜头立即跟随车头方向；漂移镜头仍以运动方向为主，但缩短多余延迟。

验收：记录修改前后同一输入序列，30/60/120 Hz 下检查转向起效、90% 方向响应、反向响应、松键继续转动量与普通稳态侧滑；漂移松 Shift 后仍保留侧滑，双喷/空落连喷保留。再执行原生技巧、完整两模式及空气墙回归，交付测量结果和录像；自动测试不代替用户对最终手感的判断。
