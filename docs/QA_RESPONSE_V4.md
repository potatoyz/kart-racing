# 响应 V4：普通转向迟滞修复

用户反馈“车很重、做不到指哪打哪”。该车辆是运动学控制器，迟滞来自控制响应，不是刚体质量。

## 根因与修改

旧版把方向输入、车头角速度和运动方向依次做慢速平滑，普通转弯也保留了明显侧滑；相机方向和位置又各加一层缓动。即使没有按 Shift，车辆也像在滑，松开方向键后仍继续转头。

本次普通抓地驾驶直接使用输入与目标转向角速度，速度方向快速贴合车头；正常转向不再有角速度拖尾。漂移和腾空仍使用独立响应，漂移松 Shift 后的惯性没有删除；漂移反打更直接。普通镜头方向随车头变化，漂移镜头仍偏向运动方向，位置跟随延迟同步缩短。

## 修改前后量化

新增 `test_response.gd`，先在原版执行并保存失败证据，再修改控制器。验收门槛保持不变。以下是平衡车型、60 Hz 物理积分、同一组固定转向输入的结果：

| 指标 | V3 修改前 | V4 修改后 |
|---|---|---|
| 车头转向角速度达到 90% | 0.367 s | 0.0167 s |
| 实际运动方向转速达到 90% | 0.533 s | 0.0333 s |
| 左右反向达到 90% | 0.633 s | 0.0500 s |
| 松键后 0.3 秒内额外转头 | 14.77° | 0° |
| 普通满舵稳态侧滑角 | 10.32° | 0.71° |

30/60/120 Hz 三种步频均通过：普通转向在首个物理步起效，运动方向 90% 响应不超过 0.051 秒，反向不超过 0.071 秒，松键额外转头不超过 1°，普通稳态侧滑不超过 2°。

这些数值测量控制器的运动积分，不是键盘、显示器或整机端到端延迟。低帧率验收录像不能单独证明毫秒级响应。

原始数据：`history/v3/response-baseline.json`、`history/v3/response-baseline-test.json`、`evidence/response-v4.json`。旧源码和旧录像保存在 `history/v3`。

## 漂移和功能回归

原有 `test_handling.gd` 门槛保持不变：松 Shift 后仍处于恢复阶段，侧滑与速度连续；反打收尾比自然收尾更快，真实长漂能获得双喷资格，并能积累、使用氮气。60 Hz 的固定输入测量中，漂移自然收尾约 0.633 秒，反打收尾约 0.233 秒。

8 个原生测试组全部通过。原生按键专项继续触发双喷、CW、CWW、WCW、空中喷和空落连喷，系统重复按键不会提前消耗第二喷。竞速赛、道具赛均完成三圈，两局仅有测试主动 R 的两次复位，未触发额外卡住恢复。

`evidence/gameplay-review.mp4` 与 `evidence/skills-review.mp4` 已更新为本版实际视口记录。转向延迟测试为本次新增；原来的“比赛能跑完”不足以证明手感直接，这次单独测量了用户指出的响应问题。

自动验证证明可测的拖尾已消除，最终是否合手仍需要用户实玩。未宣称复刻 QQ 飞车的完整驾驶模型。
