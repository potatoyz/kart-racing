# 晴空疾驰：海岸赛车节美术

本轮保持 Godot 4.5.1、V5 镜头与 V4 操控、三辆赛车、三套车手装束、竞速/道具两种模式。使用 Mivo 原生图像与模型接口替换赛车、车手和赛道周边场景；保留经过碰撞验证的道路与空气墙。

视觉语言：海蓝 #127EA5、深海蓝 #14384D、泡沫白 #F5F8EE、珊瑚 #EF8064、日光黄 #FFD05A、薄荷 #50C6B5。中文标题使用微软雅黑粗体，英文字标使用 Bahnschrift，读数用 Consolas。主界面的中心是可切换的实时赛车展台；左右是车辆参数和车手选择，下方用赛道明信片与清晰的开赛按钮收束。生成图不承担按钮文字，所有交互和信息仍为原生 UI。

素材清单及完整提示词见 `visual_asset_plan.json`：3 辆车、3 个坐姿车手、棕榈树、海滨小屋、灯塔、礁石，以及主界面背景和赛道图。Mivo GPT Image 2 生成参考图，视觉审核后用 Mivo Tripo P1 生成带纹理的 GLB。每辆车约 8,000 面，车手约 6,500 面，场景道具 1,800–4,500 面。采用坐姿角色，不把未绑定骨骼的静态模型冒充动画角色。

生成脚本 `visual_assets.py` 读取环境凭据，使用 `.cache/mivo` 恢复任务，记录模型及远端任务 ID。`images --only <id>` 生成图片，`meshes --only <id>` 要求图片已审核，`import --only <id>` 通过公开 GodotClient 导入。生成物使用 `pipeline.common.paths`，运行 ID 为 `20261026_visual_v6`。

验收：参考图与模型多角度目视检查；统一 -Z 车头朝向与实际尺寸；车手坐姿和座位贴合；轮胎接地；生成道具避开赛道及镜头；菜单在 1280×720 和 1600×900 清晰可用；换车换装、暂停/继续/设置/返回、双模式完整比赛；保留截图、原生录制视频和测试报告。实际材质、朝向、轮胎拆分方案需在生成后确定，不按提示词假定成功。
