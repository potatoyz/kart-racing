# 赛道 V3：连续曲线与空气墙

用户要求：赛道边界加空气墙，赛道改为平滑曲线，不再由长直段拼接。

方案：保留赛道整体走向及检查点/跳台索引。使用周期连续参数曲线作为唯一中心线，按细分采样生成连续路面、路肩及护栏带状网格。切线使用曲线解析导数，首尾闭合。逻辑上的 96 个路点仅用于检查点和 AI 定位，不再决定可见几何的直段长度。最近点查询局部细化到同一条曲线。

两侧空气墙与可见边界同源，使用封闭静态碰撞壳，而不是重叠盒子；从地面以下延伸到 14 米，覆盖现有跳台及氮气跳跃。独立碰撞层只约束车辆，相机不受不可见墙挤压。终点保持通行，墙体不横穿赛道。

验收：

1. 曲线首尾位置/切线连续；细分后的最大折角与弦误差有实测记录。
2. 路肩、护栏与路面之间无拼接洞；闭合碰撞面的边全部成对连接。
3. 原生车辆在地面、跳跃高度、较高空中，以及首尾接缝位置高速横撞都被拦住；沿墙滑行不被旧盒子端头卡住。
4. 两种比赛仍可跑完三圈，漂移、空中喷、落地喷、R 复位不回退。
5. 保留实际视口录像与碰撞专项报告，更新工程包。旧版源码和录像保存在 history/v2。
