## 发现与修复

1. **源模型车头朝 +X。** 从正交视图确认车灯、车头和面罩方向，在共享资产目录设置 +90° Y 旋转，运行时统一 -Z 前进。
2. **展台金属过暗。** 为独立展台和模型审阅场景补充天空环境反射，保留真实 PBR 贴图；车手服装降低金属度并提高粗糙度。
3. **叶片背面缺失。** 棕榈薄叶使用双面材质，复查背面视图。
4. **驾驶舱穿插。** 调整海燕 R 座位高度，流星 S 车手缩放至 0.88，并为三辆车记录各自的座位位置；复查九种搭配。
5. **换车后实际比赛仍可能显示旧车型。** 旧渲染缓存基于选择状态，在车辆重生前就缓存了旧模型。改为基于实际参赛车辆的车型与装束生成缓存键；UI 专项断言全部六辆车的显示资源与规则状态一致。
6. **参数条遮挡文字、肖像裁掉兔耳。** 参数条改为明确高度的原生填充图形，肖像改为完整等比显示；重拍两种分辨率。
7. **完成标记后进程被提前清理。** 给 Godot 自然退出预留时间，并主动清理静态资源缓存；验收读取最终日志，不只读取完成标记前的内容。最终完整运行和 UI 退出均无错误。

两次图像任务因服务端自动选择不支持的透明背景而失败；保留失败任务记录，明确指定白底后成功。一次 3D 提交被 429 明确拒绝，退让后重新提交成功。已接受任务使用缓存恢复，没有按网络超时盲目重复提交。

## 当前边界

车手为静态坐姿模型，尚无骨骼、手部 IK 或表情动画；轮组有独立滚动和转向动画。道路、跳台、护栏、碰撞和游戏音效仍由工程生成。没有制作 Windows 独立 EXE；源码包可用 Godot 4.5.1 导入。原 V5 呈现和旧完整比赛证据保留在 `history/v5-visual-baseline/`。
