# 喷气与轮胎特效 V8

用户已批准分层氮气、小喷/双喷脉冲、连续胎痕与轻烟尘方案。保持 Godot 4.5.1 Compatibility、现有物理和连喷规则。使用原生网格、程序化材质与有上限的世界空间粒子池，无新增付费素材或引擎安装。

氮气：按每辆车排气口布置喷流，青白大喷、橙金小喷、淡青空喷；事件负责启动脉冲，状态负责持续与消退。连喷复用同一喷流系统，不累加无限实例。启动约 0.06 秒、结束约 0.20 秒。低动态模式保留喷流，减少光粒和烟量，不增加镜头抖动。

轮胎：从真实后轮轴心与半径向路面检测接触，按速度及侧滑控制痕迹和烟量。胎痕使用连续四角网格段，沿地面法线略抬高，GPU 材质按年龄淡出；腾空、失去接地或复位断开连接。路面绘制橡胶痕，草/沙地改为尘土。

资源初始预算：4096 个胎痕段（玩家与 AI 分池）和 512 个可见粒子；预分配、复用、不逐帧创建节点。远处 AI 降低粒子与地面采样频率。暂停冻结时钟、粒子和喷流；重赛/回车库清理全部；单车复位只清理其粒子并断开其胎痕。

验收：同一原生技巧脚本的 V7/V8 对比；大喷、双喷、CWW/WCW、空落连喷；坡面接触、连续弧线、暂停/继续、复位、低动态切换；六车压力场景、无录帧性能对比与长时间容量检查；完整双模式回归。额外帧耗时目标约 1–2 ms，最终报告实际结果。
